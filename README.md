# Youtube

Youtube é uma plataforma de armazenamento de vídeos em formato mp4 para publicar conteúdos digitais, sendo acessível para todos interagirem, tornando visível publicamente para fins pessoais, educacionais, financeiros, publicitários, entretenimento e entre outros.

## Publico alvo

O publico alvo do Youtube é bastante amplo, englobando quase toda a população conectada à internet no mundo, sem restrições profundas de classe, gênero ou faixa etária.

## Funcionalidades

- Pesquisa de vídeos
- Reprodução, criação e gerenciamento de vídeos e canais
- Publicação de vídeos
- Interação (curtir, comentar e se inscrever em canais)
- Transmissões ao vivo
- Reproduções de músicas
- Sistemas de recomendações
- Recursos de monetização

## Tecnologias

- JavaScript (JS)

- C++

- Banco de Dados
- Tecnologia de IA
- Machine Learning

## Requisitos para utilização 

- computador, celular ou tablet
  
### __para assistir aos vídeos:__

- conexão de internet estável;
- navegador ou aplicativo compatível;
- Velocidade da internet adequada a qualidade de vídeo desejada;

### __para publicar videos:__

- Conta google
- Canal no Youtube
- dispositivo capaz de armazenar ou gravar vídeos;
- conexão com a internet para realizar o envio;
